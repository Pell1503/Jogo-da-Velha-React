# Jogo da Velha React

Este é um jogo da velha clássico implementado usando React.js.

## Como Jogar

1. Abra o jogo no seu navegador.
2. Dois jogadores se alternam para marcar "X" e "O" nas células da grade 3x3.
3. O primeiro jogador a conseguir três marcas consecutivas em uma linha, coluna ou diagonal vence.
4. Clique no botão "Reiniciar" para começar um novo jogo.

## Funcionalidades

* Interface intuitiva e fácil de usar.
* Detecção automática de vencedor.
* Opção de reiniciar o jogo.
* Design responsivo para diferentes tamanhos de tela.

## Tecnologias Utilizadas

* React.js
* HTML5
* CSS3
* JavaScript (ES6+)
